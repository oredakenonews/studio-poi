かきおぼ プライバシーポリシー

制定日：2026年11月21日
運営者：studio poi（金田 雅彦）

「かきおぼ」（以下「本アプリ」）は、お子さまが安心して使えるよう、個人情報をできるかぎり扱わない作りにしています。お名前、生年月日、メールアドレスをお聞きすることはありません。会員登録も、広告もありません。

1. 端末の中だけに保存する情報

練習を続けるために、次の情報をお使いの端末の中だけに保存します。

  • 使う人の呼び名（入力は任意）、学年、利き手などの設定
  • 書いた字、丸つけの結果、テストの結果
  • もらったシールと、ご家庭で決めたごほうびの文

これらは、下の「2」で協力を選ばれた場合に送る字の形をのぞき、端末の外に送信されません。端末のバックアップ（iCloud バックアップなど）には含まれます。本アプリを削除すると、これらの情報も消えます。「設定」の「記録を消す」から、いつでも消すことができます。

2. 字の判定を改善するために送る情報（保護者の方が協力を選んだときだけ）

本アプリは、最初の起動のときに、保護者向けの確認（かけ算の問題）の先で、「字の判定の改善への協力」をお願いしています。保護者の方が「協力する」を選んだときだけ、お子さまが書いた字の形を運営者のサーバーに送ります。「協力しない」を選んでも、すべての機能をお使いいただけます。選ぶまでは、何も送りません。

送るもの

  • 書いた字と、線の形・書いた順番
  • アプリの判定（通った・落ちた理由）
  • 保護者の方の丸つけ（通した・もう一回）
  • 学年、段階（なぞる・見て書く・見ないで書く）、判定の設定、指か Apple Pencil か、iPhone か iPad か、アプリのバージョン

1つの字につき送るのは、「なぞる」「見て書く」「見ないで書く」の各段階から1マスずつ（最大3マス）です。

送らないもの

  • お子さまの名前、使う人の呼び名
  • 端末を見分ける番号、広告用の識別子
  • 位置情報、連絡先、写真
  • どのご家庭かが分かるもの

通信のしくみ上、送信のときに接続元のアドレス（IP アドレス）がサーバーに届きますが、運営者はこれを保存せず、記録にも残しません。

使いみち

「正しく書いたのに通らない」「まちがった字が通る」といった判定の誤りを直すためだけに使います。広告、利用状況の分析、利用者の追跡には使いません。広告や分析の会社を含め、第三者に渡したり売ったりすることはありません。

送り先と保存する期間

  • 送り先は、運営者が Cloudflare, Inc. のサービス（Cloudflare Workers・D1。保存先はアジア太平洋地域）の上に用意したサーバーです。Cloudflare は、運営者の委託を受けてデータを預かる立場です。
  • サーバーに置くのは、最長30日です。30日を過ぎたものは自動で消します。
  • 運営者は、週に1度サーバーから手元のパソコンに取りこみ、判定の改善に使うあいだだけ保管します。使い終えたら消します。

止める・消す

  • 「設定」の「判定の改善に協力する」から、いつでも止められます。止めると、まだ送っていない分は端末から消します。
  • 送ったあとのデータは、どなたのものか分からない形で集めているため、あとからお子さま1人分だけを取り出して消すことはできません。

3. 料金と購入について

本アプリは、インストールされた時期によって、無料で使える範囲が変わります。これを確かめるために、App Store に記録されている「本アプリを最初に入手した日」を、端末の中で読み取ります。この日付を運営者に送ることはありません。

アプリ内の購入は、Apple の App Store を通じて行われます。支払いの情報は Apple が取り扱い、運営者が受け取ることはありません。購入の画面は、保護者向けの確認の先にあります。

4. お子さまの情報について

本アプリは、小学生とそれより小さいお子さまを主な利用者としています。上記「2」のとおり、字の形を送るのは保護者の方が協力を選んだときだけで、送るデータには、お子さまがだれかを特定できる情報を含めていません。広告の表示、利用者の追跡、第三者の分析ツールは使っていません。アプリの外のページへ出る所は、すべて保護者向けの確認の先にあります。

5. このポリシーの変更

内容を変更する場合は、このページでお知らせします。送る情報の種類を増やすときは、あらためてアプリの中で保護者の方の同意をいただきます。

Kakiobo Privacy Policy

Effective date: November 21, 2026
Operator: studio poi (Masahiko Kaneda)

"Kakiobo" (the "App") is designed to handle as little personal information as possible, so that children can use it safely. The App never asks for a name, date of birth, or email address. There is no account registration and no advertising.

1. Information stored only on your device

To keep track of practice, the App stores the following information only on your device:

  • Each user's nickname (optional), school grade, and settings such as handedness
  • Written characters, marking results, and test results
  • Earned stickers and the reward text set by the family

Except for the handwriting data described in section 2 (sent only if a parent chooses to help), this information is never sent off the device. It is included in device backups (such as iCloud Backup). Deleting the App also deletes this information. Records can be deleted at any time from "記録を消す" (Delete records) in Settings.

2. Information sent to improve handwriting recognition (only if a parent opts in)

On first launch, behind a parental gate (a multiplication question), the App asks the parent whether to help improve its handwriting checking. Only if the parent chooses "協力する" (Help) does the App send the shapes of written characters to the operator's server. If the parent declines, all features remain available. Nothing is sent until a choice is made.

What is sent

  • The character written, the stroke shapes, and the order of the strokes
  • The App's judgment (passed, or the reason it did not pass)
  • The parent's marking (accepted, or "one more time")
  • School grade, practice stage (trace / copy / recall), checking level, finger or Apple Pencil, iPhone or iPad, and the App version

For each character, at most three cells are sent: one from each stage (trace, copy, recall).

What is not sent

  • The child's name or the user's nickname
  • Device identifiers or advertising identifiers
  • Location, contacts, or photos
  • Anything that identifies the family

As with any internet connection, the sender's IP address reaches the server when data is sent, but the operator does not store it or keep it in logs.

How it is used

The data is used only to fix errors in the App's handwriting checking (for example, a correctly written character that does not pass). It is not used for advertising, analytics, or tracking, and it is never sold or given to third parties, including advertising or analytics companies.

Where it is sent and how long it is kept

  • The data is sent to a server the operator runs on services of Cloudflare, Inc. (Cloudflare Workers and D1; stored in the Asia-Pacific region). Cloudflare hosts the data on the operator's behalf.
  • Data stays on the server for at most 30 days; older data is deleted automatically.
  • Once a week the operator copies the data from the server to the operator's own computer and keeps it only while it is being used to improve the checking. It is deleted after use.

Stopping and deletion

  • Sending can be stopped at any time from "判定の改善に協力する" in Settings. When it is stopped, any data not yet sent is deleted from the device.
  • Because the data is collected in a form that does not show whose it is, the data of one particular child cannot be picked out and deleted after it has been sent.

3. Pricing and purchases

The range of content that is free depends on when the App was installed. To check this, the App reads, on the device, the date the App was first obtained as recorded by the App Store. This date is never sent to the operator.

In-app purchases are processed through Apple's App Store. Payment information is handled by Apple and is never received by the operator. The purchase screen is behind a parental gate.

4. Children's privacy

The App is intended mainly for elementary school children and younger. As described in section 2, handwriting data is sent only if a parent opts in, and the data contains nothing that identifies the child. The App does not show ads, does not track users, and does not use third-party analytics. Every link that leaves the App is behind a parental gate.

5. Changes to this policy

Any changes will be posted on this page. If the kinds of data sent are ever expanded, the App will ask for the parent's consent again.
